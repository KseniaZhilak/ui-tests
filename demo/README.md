# Демо-стенд

Минимальное приложение, реализующее контракт `data-testid` из основного README:
страницы `/orders` и `/users`, фильтры, таблица с `data-render-id`, пагинация
и backdoor-API `/api/test-data/orders` (POST — создать заказ, DELETE — удалить по префиксу клиента).

```bash
python3 server.py        # порт 8080
python3 server.py 9000   # другой порт (тогда тестам нужен -Dbase.url=... -Dapi.base.url=...)
```

Данные хранятся в памяти процесса: перезапуск сервера возвращает базовый набор.
Каталог нужен только для локального запуска скелета и в реальном проекте удаляется.
